# OFFSCRIPT Event Booking

A browser-based event discovery and reservation MVP.

## Run

Open `index.html` in a modern browser. No build step or dependencies are required.

## Included

- Search events by name, category, venue, or description.
- Filter the catalog by event category.
- Reserve 1–8 tickets and review or cancel reservations from **My bookings**.
- Keep reservations in browser `localStorage` across refreshes.

This prototype does not use a server, process payments, or sync reservations between devices. Event listings and prices are sample data; event photography and web fonts load from external providers.
